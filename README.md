# Punta Cana Property Analysis: Correlation of Bedrooms to Nightly Rates
**Technical Toolkit: R | Tidyverse | Simple Linear Regression**

## Project Objective
The goal of this analysis was to determine the statistical relationship between the number of bedrooms in a Punta Cana property listing and its nightly rental rate. This serves as a foundational model for understanding price drivers in the local short-term rental market.

## Methodology
* **Data Source:** Market listing data from Punta Cana (April 2026).
* **Statistical Approach:** Applied a simple linear regression model to test the hypothesis that bedroom count is a primary predictor of nightly price.
* **Tools:** Used R for data cleaning and the `lm()` function for regression analysis.

## Key Observations
* **Model Output:** Identified the average price increase per additional bedroom.
* **Visual Analysis:** Created scatter plots with a regression line to visualize the strength of the correlation and identify outliers (properties priced significantly higher or lower than the model predicts).
